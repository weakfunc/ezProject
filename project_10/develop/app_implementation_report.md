## 二、测试步骤

### 功能 1：标题区域
1. 打开 APP 首页。
2. 顶部应显示项目名称“宠物智能饲喂系统设计与实现”。
3. 项目名称下方应显示作者“韦孙麟”。

### 功能 2：系统状态显示
1. 连接 ESP32 BLE，并订阅协议特征。
2. STM32 更新 0x18、0x19 帧后，首页“系统状态”区域应刷新余量、投喂状态、当前方案、计划开关、今日次数。
3. 未收到帧时，对应字段显示 `--`。

### 功能 3：异常报警显示
1. 让 STM32 设置 TX[7] bit0、bit1 或 bit2。
2. APP “异常报警”区域分别显示食槽余量不足、电机卡堵故障、外部断电。
3. 清除报警位后，对应行恢复正常提示。

### 功能 4：计划执行启用/禁用
1. 当计划状态为禁用时，点击“启用计划执行”。
2. STM32 应收到 0x21 + 0x22 两帧，cmdCode 为 5。
3. 当状态回显为启用后，“启用”灰显，“禁用”可点；反向操作 cmdCode 为 6。

### 功能 5：手动控制舵机
1. 先禁用计划执行。
2. 点击“手动开启食槽”，STM32 应收到 cmdCode 3。
3. 点击“手动关闭食槽”，STM32 应收到 cmdCode 4。
4. 计划启用时两个按钮应灰显，并提示先禁用计划执行。

### 功能 6：当前方案选择
1. 点击方案 1~5 任一按钮。
2. STM32 应收到 cmdCode 7，planId 为所选方案。
3. STM32 回显当前方案后，对应按钮高亮。

### 功能 7：报警阈值设置
1. 点击 50g 档位。
2. STM32 应先收到 0x21 cmdCode 8，再收到 0x22 且 var4_1 为 50.0f 的 bit pattern。
3. STM32 回显 TX[5] 后，APP 显示“当前阈值：50.0 g”。

### 功能 8 和 9：计划新增/修改
1. 点击空槽位“新建”或已有槽位“修改”。
2. 在对话框中选择频率和重量。
3. 点击“确认”，STM32 应收到 cmdCode 1、planId、frequencySec、weightG。
4. 发送成功后 APP 本地行立即更新；后续以 0x1A 广播为准。

### 功能 10：计划删除
1. 点击已有方案行的“删除”。
2. STM32 应收到 cmdCode 2 和对应 planId。
3. 发送成功后 APP 本地槽位显示为“未配置”。

### 功能 11：命令序列号
1. 连续点击任意两个控制按钮。
2. 每条命令都应发送 0x21 + 0x22 两帧。
3. 第二条命令 0x22 的 var1_1 应比第一条递增 1，并保持 0~255 回绕。

## 三、自检结果

- 未修改 `BleProtocol.kt`、`BleConnectionManager.kt`、`BleAutoConnector.kt` 等通信底层文件。
- 未从 `BleProtocol.rxFrames[0x17]` 读取 STM32 业务数据。
- 业务接收仅使用 0x18、0x19、0x1A。
- 控制发送均使用 0x21 + 0x22 两帧组合。
- 未使用 Slider、SeekBar 或自定义拖动控件。
- 编译命令 `.\\gradlew.bat :app:assembleDebug` 已通过；输出中的 deprecated 警告来自既有 `BleConnectionManager.kt`，本次未修改该文件。
