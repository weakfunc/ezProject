# 应用层功能实现说明

## 已实现功能

| 功能 | 说明 |
|------|------|
| 音频播放（15种音频） | 通过 `driver_mp3` 驱动 MP3-TF-16P 模块实现。15首曲目按SD卡物理存储顺序编号（1~15），包括：雨声、海浪、森林、流水、风声、雷声、白噪、鸟鸣、雷雨、夜雨、海风、林鸟、水声、风雨、夜声。 |
| 音量调节 | 按 b6/b7 每次步进 2 级（0~30级映射为0~100%），t10 控件实时回显。 |
| 定时关闭（5/10/15/30/60分钟） | 应用层10ms任务周期内递减倒计时，时间到期后自动暂停音频并关闭灯光，循环切换：关→5m→10m→15m→30m→60m→关。 |
| WS2812灯光颜色可调 | 通过 `driver_ws2812` 驱动，10种颜色可选（关/暖白/红/橙/黄/绿/青/蓝/紫/粉），按 b4（灯光）按钮循环切换。 |
| 音频+灯光组合模式（6种） | 按 b5（模式）循环切换：助眠（雨声+暖白呼吸灯）、专注（白噪+绿色常亮）、放松（森林+蓝色流水灯）、冥想（流水+紫色呼吸灯）、活力（鸟鸣+红色流水灯）、夜眠（夜声+暖白常亮），切换时自动应用预设曲目与灯效。 |
| 串口屏交互 | 通过 `driver_tjcLCD` 驱动 USART3 接收按键帧，支持 b0~b7 八个按钮；回传 GB2312 编码文本更新控件 t3（曲目）、t4（定时）、t5（灯光）、t7（模式）、t10（音量）。 |

## 验证步骤

### 1. 音频播放

1. SD卡根目录按顺序放入15个音频文件（第1个文件对应"雨声"，依此类推）
2. 上电后按 **b1（播放）**，t3 显示"雨声"，喇叭开始播放第1首
3. 按 **b2（下一曲）**，t3 更新为"海浪"，播放第2首；按 **b0（上一曲）** 回到"雨声"
4. 连续按 b2 跳到第15首后，再按 b2 应循环回第1首；连续按 b0 从第1首应循环到第15首
5. 播放中按 **b1**，音频暂停；再按 **b1**，从暂停处继续播放

### 2. 音量调节

1. 上电默认音量约 66%（t10 显示"66"）
2. 按 **b6（音量+）** 一次，t10 增加约 6~7%（步进 2 级），喇叭音量变大
3. 按 **b7（音量-）** 一次，t10 减少约 6~7%，喇叭音量变小
4. 连续按 b6 至上限，t10 显示"100"，此后继续按 b6 数值不再增加
5. 连续按 b7 至下限，t10 显示"0"，此后继续按 b7 数值不再减少

### 3. 定时关闭

1. 按 **b3（定时）** 一次，t4 显示"5m"
2. 继续按 b3，依次切换为"10m"→"15m"→"30m"→"60m"→"关"→"5m"（循环）
3. 设为"5m"后等待约5分钟，音频自动暂停，WS2812 灯光熄灭，t4 回到"关"

### 4. WS2812 灯光颜色

1. 上电后 WS2812 应亮起暖白色呼吸灯（默认助眠模式）
2. 按 **b4（灯光）** 循环切换，t5 依次显示：暖白→白→红→绿→蓝→紫→关→暖白
3. 每次切换后 WS2812 立即更新为对应颜色
4. 切换到"关"时，所有灯珠熄灭

### 5. 音频+灯光组合模式

1. 按 **b5（模式）** 一次，t7 显示"专注"，自动播放"白噪"，WS2812 切换为白色常亮
2. 再按 b5，t7 显示"放松"，自动播放"森林"，WS2812 切换为蓝色流水灯
3. 再按 b5，t7 显示"助眠"，自动播放"雨声"，WS2812 切换为暖白呼吸灯
4. 验证三种灯效：
   - **助眠**：灯珠亮度周期性渐亮渐暗（约 20ms/帧）
   - **专注**：灯珠持续常亮，无动态效果
   - **放松**：单颗灯珠依次点亮形成流水效果（约 100ms/步）

### 6. 串口屏回传文本

使用串口助手监听 USART3 TX，操作各按钮后，观察发送的原始字节：

| 操作 | 预期发送帧（示例） |
|------|------------------|
| 切换到"雨声" | `74 33 2E 74 78 74 3D 22 D3 EA C9 F9 22 FF FF FF` |
| 定时设为"30m" | `74 34 2E 74 78 74 3D 22 33 30 6D 22 FF FF FF` |
| 灯光切换到"暖白" | `74 35 2E 74 78 74 3D 22 C5 AF B0 D7 22 FF FF FF` |
| 模式切换到"助眠" | `74 37 2E 74 78 74 3D 22 D6 FA C3 DF 22 FF FF FF` |
| 音量默认 66% | `74 31 30 2E 74 78 74 3D 22 36 36 22 FF FF FF` |

## 接线说明

| 模块 | STM32 引脚 | 说明 |
|------|-----------|------|
| MP3-TF-16P RX | USART2 TX | 波特率 9600 |
| TJC 串口屏 TX/RX | USART3 RX/TX | 波特率与屏幕设置一致 |
| WS2812 通道0 数据线 | USER_IO_1 | 16 颗灯珠 |
| WS2812 通道1 数据线 | USER_IO_2 | 16 颗灯珠 |
