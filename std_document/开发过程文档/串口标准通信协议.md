# 串口标准通信协议

## 数据包格式

固定 **16 字节**帧结构：

| 字节位置 | 值 | 说明 |
|---|---|---|
| [0] | 0x55 | 包头 1 |
| [1] | 0xAA | 包头 2 |
| [2] | 0x00~0x24 | 控制字段 |
| [3] ~ [12] | - | UTF-8 编码，最多 **10** 字节，不足补 0x00 |
| [13] | CRC8 | 对 [0]~[12] 共 13 字节的 CRC8 校验值；`ENABLE_CRC=False` 时固定为 0x00 |
| [14] | CNT | 包计数，0x00~0xFF 循环递增 |
| [15] | 0xFF | 包尾 |

## 控制字段说明

| 控制字段值 | 方向 |
|---|---|
| 0x00 | STM32 下位机向其它模块发送数据包 |
| 0x01 ~ 0x04 | 摄像头模块向 STM32 发送数据包 |
| 0x05 ~ 0x08 | 串口屏模块向 STM32 发送数据包 |
| 0x09 ~ 0x12 | STM32 向 ESP32 发送数据包 |
| 0x13 ~ 0x16 | ESP32 向 STM32 发送数据包 |
| 0x17 ~ 0x20 | ESP32 向 APP 发送数据包 |
| 0x21 ~ 0x24 | APP 向 ESP32 发送数据包 |
