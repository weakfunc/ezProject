# APP 功能实现说明

## 功能实现状态清单

| 序号 | 功能描述 | 状态 | 说明 |
|------|----------|------|------|
| 1 | 项目名称/作者顶部显示 | ✅ | `HomeScreen()` 固定顶部显示 `UserConfig.projectName` 和 `UserConfig.projectAuthor` |
| 2 | 当前水温实时显示 | ✅ | 从 `BleProtocol.rxFrames[0x18].var4b1` 解析 float，并保留 1 位小数显示 |
| 3 | 目标温度显示与调节按钮 | ✅ | 支持 `-1/+1` 与 `35/38/40/42/45℃` 快捷按钮，并立即发送 `0x21` 控制帧 |
| 4 | 按摩模式显示与切换按钮 | ✅ | 支持 停止/轻柔/标准/强劲 四种模式，按钮有选中态 |
| 5 | 定时设置按钮 | ✅ | 支持 不定时/15/30/45/60 分钟 快捷设置，并立即发送控制帧 |
| 6 | 开关机按钮（状态联动） | ✅ | 按钮文案与颜色按 STM32 上报的 `isRunning` 联动，点击后发送完整控制帧 |
| 7 | 故障/告警状态显示 | ✅ | 常显超温/干烧告警状态，异常时高亮红色，并显示故障文本 |
| 8 | 剩余定时倒计时显示 | ✅ | 从 `BleProtocol.rxFrames[0x19].var4b1` 读取秒数，按 `MM:SS` 格式显示 |

## 已实现功能的测试步骤

1. 测试顶部标题显示：
   启动 APP，进入首页。
   预期结果：页面顶部固定显示“智能控温足浴桶的设计与实现”和“黄琳”。

2. 测试当前水温显示：
   让 STM32 上报 `0x18` 帧，`var4b1` 对应 TX[4] 为 `38.5f` 的 float bit。
   预期结果：首页“系统状态”区域显示“当前水温 38.5℃”。

3. 测试目标温度调节：
   点击 `[温度 +1℃]` 或任一快捷温度按钮，例如 `[42℃]`。
   预期结果：温度设定文本立即更新，APP 发送 `cmd=0x21`，其中 `var4_1=42`。

4. 测试按摩模式切换：
   点击 `[标准]` 或 `[强劲]`。
   预期结果：对应按钮进入选中态，APP 发送 `cmd=0x21`，其中 `var1_1` 为对应模式值。

5. 测试定时设置：
   点击 `[30分钟]`。
   预期结果：页面显示“定时时长：30分钟”，APP 发送 `cmd=0x21`，其中 `var4_2=30`。

6. 测试开机按钮联动：
   初始上报 `statusByte bit0 = 0` 时，点击 `[开机]`。
   预期结果：APP 发送 `powerOn=1` 的 `0x21` 控制帧；当 STM32 后续上报 `bit0 = 1` 时，按钮变为红色 `[关机]`。

7. 测试剩余定时显示：
   让 STM32 上报 `0x19` 帧，`var4b1 = 330`。
   预期结果：“剩余定时”显示为 `05:30`。

8. 测试故障与告警显示：
   让 STM32 上报 `statusByte bit2 = 1`、`bit3 = 1`，并设置 `faultCode = 3`。
   预期结果：“超温告警”“干烧告警”显示红色异常文本，故障区显示红色“故障：超温+缺水”。

9. 测试无 BLE 连接状态：
   断开 BLE 连接或在未连接设备时进入首页。
   预期结果：状态文本显示为 `--`，按钮仍可点击；隐藏模式下可通过下拉刷新重新搜索设备。
