# Ble_Sft_1 — 开发者说明文档

## 项目概述

Android BLE 上位机工程，配套下位机：**ESP32-C3 + ESP-IDF 5.5.3 + NimBLE**。

实现功能：BLE 扫描、连接、GATT 服务发现、特征订阅(Notify/Indicate)、特征读写、RSSI 实时刷新、BLE 终端日志。

---

## 核心开关：DEVELOPER_MODE

文件：`app/src/main/java/com/example/app/userConfig.kt`

```kotlin
const val DEVELOPER_MODE = true   // 开发者模式（默认）
const val DEVELOPER_MODE = false  // 交付客户模式
```

| 行为 | DEVELOPER_MODE = true | DEVELOPER_MODE = false |
|------|----------------------|------------------------|
| 底部导航栏 | 显示（主页 / BLE搜索 / 设置） | 隐藏，仅显示 author_name 署名 |
| BLE 搜索页 | 可访问（手动扫描/连接） | 不可访问 |
| 设置页 | 可访问 | 不可访问，跳转回主页 |
| 自动扫描连接 | 不触发 | 按 MAC 地址后台自动扫描并连接 |
| 自动订阅特征 | 不触发 | 连接后自动订阅已配置的所有特征 |
| 主页下拉刷新 | 不触发 | 触发重新扫描连接 |

## UserConfig 配置项详解

### 基础信息

```kotlin
var project_name           // TopAppBar 标题
var author_name            // 客户模式底部署名，如 "designed by：qhy"
var ble_scan_page_title    // BLE 搜索页标题
var settings_page_title    // 设置页标题
```

### 目标设备

```kotlin
var esp32_device_name      // 设备广播名，用于客户模式自动连接过滤（contains 匹配）
var esp32_device_mac       // 目标 MAC，格式 "24:EC:4A:10:74:DA"，为 null 则不自动连接
```

### 自动化开关（客户模式生效）

```kotlin
var auto_filter_my_ble_devices   // 扫描页过滤显示我的设备（设置页开关）
var auto_connect_my_ble_device   // 后台自动按 MAC 连接（设置页开关）
var auto_config_ble_device       // 连接后自动订阅所有已配置特征（设置页开关）
```

### BLE UUID 配置

**Service 1**（原始数据/时间戳帧）：
```
svc uuid:  59462f12-9543-9999-12c8-58b459a2712d
chr1 uuid: 33333333-2222-2222-1111-111100000000
```

**Service 2**（数据流帧）：
```
svc uuid:  12345678-1234-5678-1234-56789ABC0000
chr1 uuid: 12345678-1234-5678-1234-56789ABC0001
chr2 uuid: 12345678-1234-5678-1234-56789ABC0002
chr3 uuid: 12345678-1234-5678-1234-56789ABC0003  ← 当前为 null（未启用）
```

> UUID 修改后无需改动其他文件，`esp32_known_service_configs` 属性会自动聚合。

## 数据帧协议（App ↔ ESP32）

### RX 帧解析（ESP32 → App）

所有帧固定 **16 字节**，Big-Endian。

| 特征 | 解析规则 | 写入变量 |
|------|----------|----------|
| Service1 Chr1 | `[0..3]` UInt32 → MCU 运行时间(秒)；`[4..15]` 12字节标志位 | `mcu_time`, `service_1_characteristic_1_flags` |
| Service2 Chr1 | `[0..15]` 4× Int32 | `rx_data_stream_1[4]` |
| Service2 Chr2 | `[0..15]` 4× Int32 | `rx_data_stream_2[4]` |
| Service2 Chr3 | `[0..15]` 4× Int32 | `rx_data_stream_3[4]` |

### TX 帧发送（App → ESP32）

| 变量 | 目标特征 | 类型 | 大小 |
|------|----------|------|------|
| `tx_data_stream_1` | Service1 Chr1 | `ByteArray` | 16 字节 |
| `tx_data_stream_2` | Service2 Chr1 | `IntArray(4)` → Big-Endian 16B | 16 字节 |
| `tx_data_stream_3` | Service2 Chr2 | `IntArray(4)` → Big-Endian 16B | 16 字节 |
| `tx_data_stream_4` | Service2 Chr3 | `IntArray(4)` → Big-Endian 16B | 16 字节 |

调用 `BleConnectionManager.writeCharacteristic(serviceUuid, characteristicUuid, payload)` 发送，写入后调用 `recordOutgoingMessage()` 记录到 BLE 终端。

## BleConnectionManager 关键 API

```kotlin
// 连接设备
BleConnectionManager.connect(context, device, deviceName, rssi)

// 断开当前设备
BleConnectionManager.disconnectCurrent()

// 读特征
BleConnectionManager.readCharacteristic(serviceUuid, characteristicUuid): Boolean

// 写特征
BleConnectionManager.writeCharacteristic(serviceUuid, characteristicUuid, value): Boolean

// 订阅/取消订阅（自动切换）
BleConnectionManager.toggleCharacteristicSubscription(serviceUuid, characteristicUuid): BleSubscriptionToggleResult

// 可观察状态（Compose State）
BleConnectionManager.connectedDeviceInfo        // ConnectedBleDeviceInfo?
BleConnectionManager.discoveredServices         // List<BleGattServiceUi>
BleConnectionManager.terminalEntries            // SnapshotStateList<BleTerminalEntryUi>（最多 200 条）
BleConnectionManager.deviceStates              // Map<address, BleDeviceConnectionStatus>
```

## 客户模式自动化流程

```
App 启动 / onStart()
    └─ startHiddenModeBleFlowIfNeeded()
           ├─ 检查权限 → 请求权限
           ├─ 检查蓝牙是否开启 → 请求开启
           └─ 后台 BLE 扫描 (backgroundScanCallback)
                  └─ 匹配 esp32_device_mac → connect()
                         └─ onConnectionStateChange → discoverServices()
                                └─ onServicesDiscovered
                                       └─ maybeAutoConfigureBleDeviceInHiddenMode()
                                              └─ 遍历 esp32_known_service_configs
                                                     └─ toggleCharacteristicSubscription()
                                                            └─ 失败重试最多 6 次（间隔 300ms）
```

下拉刷新：触发 5 秒手动扫描窗口，找到目标设备后立即连接。

## 新功能开发指引

### 添加新的 RX 数据流

1. 在 `userConfig.kt` 中添加新变量：`var rx_data_stream_4 by mutableStateOf(IntArray(4))`
2. 在 `BleConnectionManager.parseIncomingFrame()` 中添加对应 UUID 的 `when` 分支

### 添加新的 BLE Service/Characteristic

1. 在 `userConfig.kt` 添加 UUID 变量
2. 更新 `esp32_known_service_configs` 的 `get()` 方法，加入新 service 配置
3. 更新 `parseIncomingFrame()` 添加解析逻辑

### 扩展客户 UI（主页）

修改 `MainActivity.kt` 的 `HomeScreen` Composable，在 `!UserConfig.DEVELOPER_MODE` 分支下添加自定义卡片。
