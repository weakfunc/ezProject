# 功能实现文档 — 液位高度测量系统 APP

## (a) 功能实现状态清单

| 序号 | 功能描述 | 状态 | 说明 |
|------|---------|------|------|
| 1 | 液位高度实时显示 | ✅ | 读取 `rxFrames[0x18].var4b1`，`Float.fromBits()` 转换，格式 `"%.0f mm"` |
| 2 | 液位变化量显示（带符号） | ✅ | 读取 `rxFrames[0x18].var4b2`，格式 `"%+.0f mm"` 强制显示正负号 |
| 3 | 距液面原始距离显示 | ✅ | 读取 `rxFrames[0x19].var4b1`，格式 `"%.0f mm"` |
| 4 | 系统状态显示（校准中/正常） | ✅ | 读取 `rxFrames[0x18].var1b1`，0=橙色"正在校准..."，1=绿色"正常工作" |
| 5 | 报警上限回显 | ✅ | 读取 `rxFrames[0x19].var4b2`，>0 显示数值，否则显示"未设置" |
| 6 | 高限阈值输入框 + 设置按钮 | ✅ | `OutlinedTextField` + 数字键盘，共用"设置阈值"按钮 |
| 7 | 低限阈值输入框 + 设置按钮 | ✅ | `OutlinedTextField` + 数字键盘，共用"设置阈值"按钮 |
| 8 | 输入校验与 Toast 提示 | ✅ | 按需求顺序四级校验，全通过后调用 `sendAlarmThreshold()` |

## (b) 测试步骤

| 功能 | 测试方法 | 预期结果 |
|------|---------|---------|
| 液位高度显示 | BLE 连接后，对比 OLED 与 APP 显示值 | 两端数值一致，误差 ≤ 1 mm |
| 状态切换 | 设备上电后观察 APP 状态区 | 约500ms内从"正在校准..."变为"正常工作" |
| 发送高限阈值 | 输入高限800、低限200，点设置 | "当前高限"字段更新为 800 mm |
| 输入校验-空值 | 清空输入框点设置 | Toast "请输入有效数值" |
| 输入校验-高≤低 | 高限200低限800，点设置 | Toast "高限须大于低限" |
| 输入校验-超范围 | 输入1500，点设置 | Toast "阈值超出范围（最大1000mm）" |
| 校准中状态 | 设备刚上电，观察数据区 | 所有数值显示"---" |
