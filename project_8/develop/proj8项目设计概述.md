## 设计方案概述

长方形板，锂电池单独在底层，其余在顶层，测温模块留接口，在机械上固定

**每次上电OLED不显示，必须上电后复位一下oled才会显示，解决这个bug**                     
                                                                  
  Read 1 file (ctrl+o to expand)                                                      
                                         
● 根本原因已经很清楚了。                                                              
                                                                                      
  DRIVER_OLED_Init() 上电后立即向 SSD1306 发送初始化命令，但 SSD1306 数据手册要求 VCC 
  稳定后需约 100ms 才能接受 I2C 命令。复位时 OLED 早已上电完成所以没问题，冷启动时 MCU
   已经跑起来了但 OLED 还没准备好，初始化命令全部被忽略。                             
                                                                                      
  修复方式：在 task 层（RTOS 已运行，可用 osDelay）调用 DRIVER_OLED_Init() 前等
  100ms。driver 层不引入 RTOS 依赖。

**给电池电压ADC采集加滤波，现在总是100%和80%之间跳**  

  滤波算法：IIR 指数移动平均，公式：
  V_filtered = V_filtered × 0.9 + V_raw × 0.1
                                                                                      
  参数选择：α = 0.1，采样周期 500ms，时间常数约 4.5 个采样（≈2.25 秒）。电源纹波和量化
  噪声（毫秒量级抖动）完全被平滑，电池真实电量变化（数分钟）不受影响。                
                                                            
  首次初始化：第一次调用直接用原始值初始化 adcVoltFiltered，避免从 0V
  开始缓慢爬升的冷启动问题。
