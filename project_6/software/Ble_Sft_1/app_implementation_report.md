# APP 功能实现报告 — QR码自动分拣系统

## (a) 功能实现状态清单

| 序号 | 功能描述 | 状态 | 说明 |
|------|---------|------|------|
| 1 | 系统使能状态显示 | ✅ | 绿色"使能" / 红色"禁用"，读取 CMD 0x18 var1b1 |
| 2 | 运行时间显示（秒，带小数） | ✅ | 格式 `X.X s`，读取 CMD 0x18 var4b1（单位 10ms）|
| 3 | 分拣状态显示（含保护状态） | ✅ | 7 种状态文本 + 颜色映射，读取 CMD 0x17 var1b1 |
| 4 | 目标地点显示（T01~T10/无数据/未知） | ✅ | 支持二进制(0x00~0x09)和ASCII(0x30~0x39)编码 |
| 5 | 丝杆位置显示（cm，1位小数） | ✅ | Float.fromBits 转换，格式 `X.X cm`，读取 CMD 0x17 var4b1 |
| 6 | QR 累计计数显示 | ✅ | 读取 CMD 0x17 var4b2 |

## (b) 测试步骤

| 功能 | 测试方法 | 预期结果 |
|------|---------|---------|
| 丝杆位置 | BLE 连接后对比 OLED 与 APP 显示值 | 两端数值一致，误差 ≤ 0.1 cm |
| 分拣状态 | 扫描 QR 码后观察 APP 状态区 | 状态依次切换 等待扫码→识别延时→丝杆移动→执行分拣→返回原点→等待扫码 |
| 目标地点 | 扫描 QR 码 0x03，观察 APP | 显示 "T04" |
| 系统使能 | 按下板载 KEY0，观察 APP | 使能状态切换，颜色在绿/红间变化 |
| 运行时间 | 设备运行约 10s 后对比 OLED | 两端时间一致（误差 ≤ 0.1s） |
| 保护状态 | 触发超温/过流后观察 APP | 状态显示红色"超温保护"或"过流保护" |

## (c) 修改说明

**修改文件**：`app/src/main/java/com/example/demo_1/MainActivity.kt`

**修改内容**：
- 替换 `HomeScreen()` 函数中的 UI 内容（保留函数签名和 LaunchedEffect 不变）
- 新增 `ProtoFieldRow()` 私有组件（双列标签-值布局，支持可选颜色参数）
- 移除旧版传送带控制按钮和包裹信息 UI
- 删除不再使用的 Button、ButtonDefaults、HorizontalDivider 导入
- 新增 `androidx.compose.ui.Alignment` 导入

**数据读取映射**：

| 显示字段 | 帧 CMD | 槽位 | 转换方式 |
|---------|-------|------|---------|
| 丝杆位置 | 0x17 | var4b1 | `Float.fromBits(...)` |
| QR 计数 | 0x17 | var4b2 | 直接显示 Int |
| 分拣状态 | 0x17 | var1b1 | when 映射文本+颜色 |
| QR 目标 | 0x17 | var1b2 | 范围判断映射 T01~T10 |
| 运行时间 | 0x18 | var4b1 | `/100` 取秒，`/10%10` 取 0.1s 位 |
| 系统使能 | 0x18 | var1b1 | `!= 0` 判断 |
