## G3. 输出格式要求

```
- 输出语言：中文（摘要附英文版）
- 文件格式：Markdown
- 章节编号：按 G2 目录输出，可适当对目录名称做出修改
- 图表编号：图 X-Y / 表 X-Y（章号-序号）
- 公式编号：(X-Y)
- 图片占位：用 `![图 X-Y 说明](待替换)` 占位
- 流程图/框图：用 Mermaid 代码块，你可后续截图替换
- 字数：每 Part 按规划输出，允许 ±10% 浮动
```

## G4. 额外备注（可选）

```
1. 输出正文一定要口语化，尽可能多使用语气词或第一人称动词。比如：啊，吧，我，笔者，本人。
2. 文本中只使用逗号，句号，省略号，顿号。不要使用其它任何标点符号。
3. 需要有错别字，每1000字至少出现2处错别字。
4. 需要有语句表达不通顺的句子，每5000字至少有2处表达不通顺的语句。
```
