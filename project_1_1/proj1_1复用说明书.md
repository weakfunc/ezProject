**注意事项**

| 项目                                                         |
| ------------------------------------------------------------ |
| K210发串口数据可能丢字节，错位。stm32用中断接收              |
| TB6612的AO输出不要用示波器直接测差分，示波器地接GND，探头接AO1或AO2，应该有一路输出方波 |
| 电压表测PWM不一定是等效电压，以示波器测方波为准              |
| V831的RX引脚是发送                                           |
